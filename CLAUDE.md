- As regras de projeto, stack, design e SEO estão em `AGENTS.md` (importado acima). **Não duplicar** regras aqui;

- Para tarefas novas, comece em **modo de planejamento**: descreva o plano em poucos passos e aguarde aprovação.
- Prefira **editar arquivos existentes** a criar novos; não crie documentação nem arquivos extras sem pedido.
- Use o servidor de dev para validar (`npm run dev -- --host`) e finalize sempre com `npm run build`.
- Faça uma seção por sessão/tarefa; use `/clear` entre seções para manter o contexto enxuto.
- Quando houver conflito entre o mockup e o `AGENTS.md` (ex.: texto justificado no mobile, contraste do branco
  sobre laranja), **vale o `AGENTS.md`** — e avise a divergência no resumo final.
- Nunca commitar chaves, tokens ou arquivos `.env`.
